# Hareesh Ravilala — React.js Developer Portfolio

A responsive, single-page React portfolio built with Vite, Bootstrap 5, and React Icons.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually `http://localhost:5173`).

## Production build

```bash
npm run build
npm run preview
```

## Resume

The Home section's **Download Resume** button downloads `public/resume.pdf`. Keep the supplied PDF at that path when updating the resume.

## Contact

The Contact section provides direct email and phone links, a location link for Hyderabad, India, and links to LinkedIn and GitHub.
